CVE-2026-85046 — late-page reclaim v38

This one-shot diagnostic extends v37 to stale addresses in the second half of a regular V8 page. It derives one benign filler size from the stale page offset, waits for the v34 two-control GC signal, then performs exactly one filler allocation, one phase-0 payload allocation, and one immediate stale length-marker read. It performs no header write, arbitrary-memory access, native-code execution, sandbox escape, file access, or network operation.
